# Features

This folder contains vertical slices organized by feature:

- **Tenants**: Tenant management endpoints and logic
- **Users**: User management endpoints and logic
- **Bookings**: Booking operations endpoints and logic
- **Schedules**: Schedule management endpoints and logic

Each feature slice contains:
- Endpoints (FastEndpoints)
- Handlers/Services
- Validators (FluentValidation)
- Feature-specific logic
